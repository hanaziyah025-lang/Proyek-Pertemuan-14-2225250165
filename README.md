## Deskripsi Proyek
Program Analisis Nilai Mahasiswa merupakan program sederhana untuk mengolah data nilai mahasiswa. Program ini dibuat menggunakan Python dan dijalankan melalui terminal.

## Tujuan
Program ini bertujuan membantu pengguna menghitung dan menganalisis nilai mahasiswa secara lebih mudah.

## Fitur Program
1. Membaca data mahasiswa dari file teks.
2. Memvalidasi data nilai.
3. Menghitung nilai rata-rata.
4. Menentukan nilai tertinggi dan terendah.
5. Menghitung jumlah mahasiswa yang lulus dan tidak lulus.
6. Menampilkan hasil analisis.
7. Menyimpan laporan hasil analisis.
